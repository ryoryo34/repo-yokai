# Repo Yokai

[English](./README.md) | [日本語](./README.ja.md)

Turn evidence-backed changes in code analysis into yokai encounters on pull requests.

## Status

Early development. This repository currently contains the project brief and issue-driven workflow; the first runnable demo is being implemented in a dedicated issue. Planned features are not available yet.

## Development

See [vision](docs/VISION.md), [workflow](docs/WORKFLOW.md), and [issues](https://github.com/ryoryo34/repo-yokai/issues). One issue corresponds to one Codex session and one implementation branch. Setup instructions will be added with the runnable demo.
