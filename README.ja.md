# Repo Yokai

[English](./README.md) | [日本語](./README.ja.md)

PRのコード分析結果を妖怪として可視化し、出現から退治まで追いかけるツール。

## 開発状況

開発初期です。現在は企画とIssue駆動の開発方針を収録しており、最初の動くデモを専用Issueで実装します。構想段階の機能はまだ使えません。

## 開発

[構想](docs/VISION.md)、[開発フロー](docs/WORKFLOW.md)、[Issue](https://github.com/ryoryo34/repo-yokai/issues)を参照してください。1 Issueにつき1つのCodexセッションと実装ブランチを使います。起動手順は動くデモとともに追加します。
